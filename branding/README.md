# Libre Tab — brand

The mark is a campfire: a pick-shaped flame folded into flat, faceted
planes (a nod to the Flutter style, but its own drawing), sitting on two
crossed logs. The sparks flying off it are the chords everyone plays first:
G, C, D, Em, Am. **Camp** (logs), **fire** (the flame), **guitar** (the pick
shape) and **tab** (the chords).

Everything here is generated by one script. Edit it, then re-run it:

```sh
python3 -m pip install fonttools  # once: the chords become outlines
python3 branding/generate.py      # needs Google Chrome for SVG → PNG
dart run flutter_launcher_icons   # copies the app icon into ios/ and android/
```

After `flutter_launcher_icons`, revert its change to
`ios/Runner.xcodeproj/project.pbxproj` (`git checkout` it). The tool
rewrites an unrelated build setting.

## Files

| File | Use |
|---|---|
| `app_icon/app-icon.png` | iOS icon and Android legacy icon (1024², opaque) |
| `app_icon/android-foreground.png` | Android adaptive icon foreground (background `#100D0A`) |
| `png/mark.png` | The mark on transparent: stickers, slides, web |
| `png/mark-red-night.png` | The mark in the Red night palette |
| `png/mark-mono-cream.png`, `mark-mono-dark.png` | One colour, with real cut-outs: stamps, embroidery, merch |
| `png/avatar-dark.png`, `avatar-light.png`, `avatar-red-night.png` | Profile pictures (square, safe for circle crops) |
| `png/lockup-on-dark.png`, `lockup-on-light.png` | Mark plus wordmark, horizontal, transparent |
| `png/social-og-1200x630.png` | Link preview (Open Graph / X card) and GitHub social preview |
| `png/social-header-1500x500.png` | X / Mastodon header banner |
| `png/social-post-1080.png` | Instagram / Facebook square post |
| `png/social-story-1080x1920.png` | Stories / Reels / TikTok cover (Spanish tagline) |
| `png/play-feature-1024x500.png` | Google Play feature graphic |

In the app, `assets/images/mark.png` and `mark-red-night.png` are these
marks at 256 px: the tabs' header logo (mark + "Libre Tab" set in Fraunces
by the app, so it takes each theme's colour) and the empty songbook.

Every PNG has an SVG next to it in `svg/`. The lockup and social SVGs embed
their fonts (Fraunces and Atkinson Hyperlegible, both SIL OFL).
